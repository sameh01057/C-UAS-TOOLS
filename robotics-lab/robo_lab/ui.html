Robotics Safety Lab — Measured Attack Impact

An autonomous warehouse robot (AMR). Real Kalman-tracker perception pipeline; each attack genuinely corrupts the sensor data, so the robot makes an unsafe decision from a valid command. Results are measured, not scripted, and averaged over several random runs. The same method as our C-UAS lab, on a general robot.
⚠
Scope — read before quoting any number. This is a representative lab: perception-sensor specifications are real (manufacturer-published, sources in each ⓘ) but the behaviour is modelled from those specs — it is not a real fielded robot, not any customer's deployment, and not an exploit of a real robot's buses. Real ranges are scaled down (÷3) for a fast, reproducible run. The effects are faithful in kind to how these attacks degrade a real autonomous system; exact magnitudes on any live robot come only from an actual assessment.

Results are averaged over several random runs, so values can be fractional and a result within run-to-run noise shows as “~” (no real effect) rather than a misleading ±1. An attack can only ever harm safety, so safely-handled hazards are capped at the clean baseline for each run — an attack can never read as improving safety. Note: the Safely handled and Collisions charts mirror each other by design — a hazard that isn't handled collides (Safely handled + Collisions + Unresolved = total hazards).
