Scope — read before quoting any number. This is a representative lab: component specifications are real (manufacturer-published, sources in each ⓘ) but the behaviour is modelled from those specs — it is not a real fielded C-UAS, not any customer's deployment, and not an exploit of real RF/C2 links. Real ranges are in kilometres; the lab world is scaled down (÷3) for a fast, reproducible run. The effects are faithful in kind to how these attacks degrade a real system; exact magnitudes on any live system come only from an actual assessment.

Results are averaged over several random runs, so values can be fractional and a result within run-to-run noise shows as “~” (no real effect) rather than a misleading ±1. An attack can only ever harm the defence, so real kills are capped at the clean baseline for each run — an attack can never read as improving the system. Note: the Neutralised and Leaked charts mirror each other by design — a drone that isn't neutralised leaks, so kills-lost ≈ leaks-gained (the accounting balances: Neutralised + Leaked + In-flight = total hostiles).
